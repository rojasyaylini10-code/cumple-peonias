# Página de cumpleaños con peonías 🌸

## Archivos
- `index.html` → estructura de la página.
- `style.css` → diseño, cascada, peonías y animaciones.
- `script.js` → nombre, mensaje y efectos.

## Personalizar
Abre `script.js` y cambia:

```js
const CONFIG = {
  nombre: "Nombre de tu amiga",
  mensaje: "Tu mensaje..."
};
```

## Música opcional
Puedes poner un archivo llamado `music.mp3` en esta misma carpeta y descomentar la etiqueta `<audio>` que está al final de `index.html`.
Ten en cuenta que los navegadores suelen bloquear la reproducción automática; por eso la página ya trae un pequeño efecto de sonido que se activa al tocar el botón.

## Publicar gratis
Puedes subir estos archivos a un repositorio de GitHub y activar GitHub Pages.
Tu página puede quedar con una dirección como:
